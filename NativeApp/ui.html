一键封堵高危漏洞

关闭默认共享 / 远程桌面 / NetBIOS，禁用 SMBv1，NTLM 强制 NTLMv2，并对预置的 80+ 个高危端口下发防火墙入站阻断规则。

预置策略覆盖

终端防勒索（MS17-010 / 永恒之蓝）、远程入侵封堵、弱服务收敛、数据库暴露面收敛，均已在「预置封堵」页就绪。

操作前须知

封堵会真实修改系统服务、注册表与防火墙规则。若本机需对外提供 SMB / FTP / 数据库服务，请先在「预置封堵」页填写保留端口，或使用对应的服务器模式。

预置高危漏洞封堵

按场景选择策略，或一键执行全量加固。策略逻辑源自原 v8.29 批处理，已完整迁移。

严重勒索防护

策略一 · 终端防勒索加固

关闭 445/139、禁用 SMBv1、删除默认共享、强制 SMB 签名与 NTLMv2，阻断 MS17-010 永恒之蓝等基于 SMB 的横向渗透。

严重远程入侵

策略二 · 远程入口封堵

禁用 3389 远程桌面、22 SSH、23 Telnet、5985/5986 WinRM，关闭 135 RPC 监听面的暴露，收敛远程管理入口。

高危弱服务

策略三 · 弱服务收敛

禁用 FTP / ICS / DNS / SNMP 服务，关闭 NetBIOS 与 NetBT（137/138/139），阻断匿名共享与弱社区字串风险。

高危数据泄露

策略四 · 数据库暴露面收敛

阻断 1433/3306/1521/5432/6379/27017/9200 等数据库与中间件端口入站，并检测未授权访问风险（仅提示，不修改数据库配置）。

推荐全量

策略五 · 一键全量加固

按原脚本 [C] 客户端模式执行：服务加固 + 防火墙阻断全部预置端口 + 数据库授权检查 + 状态复核，适合普通办公终端。

本机需对外提供文件时，使用白名单模式放行指定 IP（原脚本 [S]/[F]），在保留必要服务的同时封堵其余高危端口。
